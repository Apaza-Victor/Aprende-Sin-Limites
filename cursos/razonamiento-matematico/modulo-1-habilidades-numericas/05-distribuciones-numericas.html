Distribuciones numéricas

Módulo 1 · Habilidades numéricas

Objetivo Reconocer cuando una lista de numeros forma una distribucion y usar el valor central para responder preguntas de posición.

Que es una distribucion numerica

Una distribucion es un conjunto de numeros ordenados de menor a mayor. Tambien se puede llamar distribucion cuando los datos estan separados y se pueden leer por posicion.

Posiciones

  • El primer dato es el menor.
  • El ultimo dato es el mayor.
  • Los datos del medio ocupan las posiciones intermedias.
  • Si la cantidad de datos es impar, hay un valor central exacto.
  • Si es par, el valor central es el promedio de los dos datos del medio.

Rango

  • Rango = dato mayor - dato menor
  • El rango resume cuanto se extiende la distribucion.
  • Dos distribuciones pueden tener el mismo centro y muy distinto rango.

Lectura de graficos

  • Un grafico de barras compara cantidades entre categorias.
  • Un grafico circular muestra partes de un todo, y las sumas dan 100 por ciento.
  • Un grafico de lineas muestra cambios a lo largo del tiempo.
Antes de responder, calcula el rango. Si te piden el dato que mas se repite, eso es la moda, y no el centro.

La moda, la mediana y la media son tres medidas distintas. La moda es el mas frecuente, la mediana es el valor central, y la media es el promedio aritmetico. No se pueden sustituir entre si.

Ejemplo resuelto

Se pide el rango, la moda y la mediana de: 3, 5, 5, 7, 9, 11, 11.

Metodo 1: ordenar

  • La lista ya viene ordenada: 3, 5, 5, 7, 9, 11, 11.

Metodo 2: el rango

  • Dato mayor = 11, dato menor = 3.
  • Rango = 11 - 3 = 8.

Metodo 3: la moda

  • El 5 aparece dos veces y el 11 aparece dos veces.
  • Hay dos modas: 5 y 11. Se dice que la distribucion es bimodal.

Metodo 4: la mediana

  • Hay 7 datos, cantidad impar, asi que la mediana es el dato de la posicion 4.
  • La posicion 4 es el 7.
  • Mediana = 7.
  • Resultado: rango 8, moda doble 5 y 11, mediana 7.

Consejo que suma puntos

Cuenta la cantidad de datos antes de elegir la mediana. Si son impares, toma el dato central; si son pares, promedia los dos centrales. Contar mal los datos es el error que mas se repite en este tema.
