Problemas sobre edades

Módulo 2 · Procesos y planteo de problemas

Objetivo Resolver problemas de edades usando una sola incognita y evitando el error de sumar dos veces la edad pedida.

El problema clasico de las edades

En estos problemas hay dos edades que estan relacionadas. Si una es el doble, la suma, o la mitad de la otra, la incognita debe ser una sola.

Como se plantea

  1. Llama x a la edad que se pide en el enunciado.
  2. La otra edad se escribe en funcion de x: si es el doble, 2x; si es la mitad, x/2; si le faltan n anos, x + n.
  3. La suma de ambas es el dato que da el problema.
  • x + 2x = total, o la forma que corresponda.

El error clasico

Si pides la edad del mayor y escribes x, pero luego planteas x + 2x, estas usando x para el menor.

La solucion es escribir con claridad a quien representa x antes de plantear. Muchos errores vienen de no declarar esa decision.

Edades en el tiempo

Cuando el problema dice dentro de n anos o hace n anos, la edad sera x + n o x - n, y el resto de cantidades tambien cambia.

  • Si hoy el padre tiene el doble que el hijo, dentro de 10 anos la relacion ya no sera doble.
  • Por eso conviene comprobar la respuesta en el presente y en el futuro.

Comprobacion

Sustituye la edad encontrada en el enunciado original. Si la suma no da el total, la ecuacion esta mal planteada, no mal resuelta.

Ejemplo resuelto

La suma de las edades de un padre y su hijo es 54, y el padre tiene el doble que el hijo. Cuantos años tiene cada uno.

Metodo 1: elegir la incognita

  • Se pide la edad del hijo, que es la menor.
  • x es la edad del hijo.

Metodo 2: expresar la otra edad

  • El padre tiene el doble, asi que su edad es 2x.

Metodo 3: plantear

  • x + 2x = 54
  • 3x = 54

Metodo 4: resolver y comprobar

  • x = 54 / 3 = 18
  • El padre entonces tiene 2 * 18 = 36.
  • Comprobacion: 18 + 36 = 54. Correcto.
  • Conclusiones: el hijo tiene 18 anos y el padre 36.
  • Ojo: el padre tiene 36 anos y el hijo 18, asi que la diferencia es de 18 anos, no de 36.

Consejo que suma puntos

Declara con una frase cual de las dos edades es x, y despues no cambies el significado. Escribir el nombre de quien representa x en el primer renglon evita la mayoria de los errores de planteo.
