Ecuaciones cuadráticas

Módulo 2 · Álgebra

Objetivo Resolver ecuaciones de segundo grado por factorización y por fórmula general, e interpretar el discriminante.

Una ecuación cuadrática tiene la forma ax² + bx + c = 0, con a distinto de cero. Siempre tiene dos soluciones, que pueden coincidir, y el término independiente debe ser 0 para poder factorizar.

Método 1: factorización

Buscas dos números que multiplicados den c y sumados den b. Si los encuentras, escribes el producto de los binomios y pones cada factor en cero. Ejemplo: x² − 5x + 6 = 0, porque 2 × 3 = 6 y 2 + 3 = 5, así que (x − 2)(x − 3) = 0.

Método 2: fórmula general

Cuando no se puede factorizar fácilmente se usa:

x = (−b ± raíz de (b² − 4ac)) / (2a)

La expresión de adentro es el discriminante D = b² − 4ac, y decide cuántas soluciones hay:

  • Si D es positivo: dos soluciones reales distintas.
  • Si D es cero: una solución doble.
  • Si D es negativo: no hay soluciones reales.

Relación con la parábola

Las soluciones son los puntos donde la parábola corta el eje horizontal. Si el discriminante es negativo, la parábola ni siquiera toca ese eje, y por eso no hay soluciones reales que dibujar.

Ejemplo resuelto

Resuelve 2x² − 7x + 3 = 0.

Método de la factorización, el más rápido cuando funciona

  • Busco dos números cuyo producto sea 3 y cuya suma sea −7: son −1 y −6.
  • Reparto el coeficiente de x entre los dos factores: (2x − 1)(x − 3) = 0.
  • Pongo cada factor en cero: 2x − 1 = 0 da x = 1/2, y x − 3 = 0 da x = 3.

Método de la fórmula general, que siempre funciona

  • Con a = 2, b = −7 y c = 3, el discriminante es D = b² − 4ac = 49 − 24 = 25.
  • Como es positivo, hay dos soluciones reales distintas, como esperaba.
  • Aplico x = (−b ± raíz de D) / (2a) = (7 ± 5)/4, lo que da 3 y 1/2. Las mismas dos raíces.

Método de las fórmulas de Viète, que no calcula pero controla

  • La suma de las raíces es −b/a = 7/2 = 3,5. En efecto, 3 + 0,5 = 3,5.
  • El producto de las raíces es c/a = 3/2 = 1,5. En efecto, 3 × 0,5 = 1,5.
  • Si mis dos valores no cumplieran estas dos relaciones, habría que revisarlos.

Comprobación de cada raíz

  • 2(3)² − 7(3) + 3 = 18 − 21 + 3 = 0. Correcto.
  • 2(1/2)² − 7(1/2) + 3 = 0,5 − 3,5 + 3 = 0. También correcta.

Consejo que suma puntos

Intenta siempre factorizar antes de usar la fórmula: es más rápido y evita errores de signo. Y cuando sí uses la fórmula, escribe primero el discriminante y decide con él si hay una, dos o ninguna solución real, porque eso mismo suelen preguntarlo.
