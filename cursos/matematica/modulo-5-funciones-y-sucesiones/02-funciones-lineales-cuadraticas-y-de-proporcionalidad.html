Funciones lineales, cuadráticas y de proporcionalidad

Módulo 5 · Funciones y sucesiones

Objetivo Representar e interpretar funciones lineales y cuadráticas, reconociendo pendiente, vértice y puntos de corte.

La función lineal es f(x) = mx + n, donde m es la pendiente y n la ordenada en el origen. Su gráfica es una recta.

Significado de la pendiente

m = tanα = Δ yΔ x
  • m > 0: recta creciente.
  • m < 0: recta decreciente.
  • m = 0: función constante y = n, una recta horizontal.

Función cuadrática

f(x) = ax2 + bx + c, a ≠ 0

Su gráfica es una parábola abierta hacia arriba si a > 0 y hacia abajo si a < 0.

### Vértice

xv = -b2a, yv = f(xv) = -Δ4a, Δ = b2 - 4ac

El eje de simetría es la recta x = xv.

### Puntos de corte

  • Con el eje OY, se pone x = 0 y sale el punto (0, c).
  • Con el eje OX, se pone y = 0 y se resuelven las raíces de ax2 + bx + c = 0 según el valor de Δ:
a < 0, a = 0, a > 0

Forma canónica

f(x) = a(x - h)2 + k, V = (h, k)
Para pasar de la forma general a la canónica basta con completar cuadrados. Así el vértice se identifica de un vistazo y la parábola se lee sin operar.

Ejemplo resuelto

Dada f(x) = x2 - 4x + 3, halla vértice, eje de simetría, puntos de corte y forma canónica.

Vértice y eje

xv = --42 = 2, yv = f(2) = 4 - 8 + 3 = -1

Así V = (2, -1) y el eje es x = 2.

Puntos de corte

  • Con el OY: x = 0 ⇒ (0, 3).
  • Con el OX: x2 - 4x + 3 = 0 ⇒ (x-1)(x-3) = 0 ⇒ (1, 0) y (3, 0).

Forma canónica

f(x) = (x - 2)2 - 1

Comprobación

Al evaluar en el vértice: (2-2)2 - 1 = -1, que coincide con yv. Y las raíces de la canónica son 2 - 1 = 1 y 2 + 1 = 3, simétricas respecto a x = 2 como debe ser.

Las dos comprobaciones dan el mismo vértice y las raíces simétricas confirman que el cálculo está bien.

Consejo que suma puntos

Si el coeficiente a < 0, la parábola abre hacia abajo y el vértice es un máximo, no un mínimo. Anótalo siempre, porque en problemas de optimisation ese matiz decide si buscas el techo o el suelo de la curva.
