Funciones exponenciales y logarítmicas

Módulo 5 · Funciones y sucesiones

Objetivo Aplicar las propiedades de exponentes y logaritmos para resolver ecuaciones y analizar funciones exponenciales.

La función exponencial es f(x) = ax con a > 0, a ≠ 1, y su dominio es todo R.

Propiedades básicas

ax+y = ax ay, ax-y = axay
(ab)x = abx, a0 = 1, a-x = 1ax

El logaritmo es la operación inversa

loga y = x ⇔ ax = y

con las condiciones a > 0, a ≠ 1 y y > 0.

Propiedades del logaritmo

loga(xy) = loga x + loga y, logaxy = loga x - loga y
loga(xk) = k loga x, loga a = 1, loga 1 = 0

Cambio de base

loga b = ln bln a = log10 blog10 a = 1logb a
El logaritmo solo existe para argumentos positivos. Antes de dar por buena una solución logarítmica, compruébala en la expresión original: casi siempre es un argumento negativo.

Ejemplo resuelto

Resuelve 2x + 2x+1 = 12.

Factor común

  • Como 2x+1 = 2 · 2x, se puede sacar 2x: 2x(1 + 2) = 12.
  • Entonces 3 · 2x = 12 ⇒ 2x = 4 = 22 ⇒ x = 2.

Comprobación

22 + 23 = 4 + 8 = 12

---

Resuelve log(x) + log(x - 3) = 1 en base 10.

Condición de existencia primero

  • Para que ambos logaritmos existan: x > 0 y x - 3 > 0, luego x > 3.

Aplicamos las propiedades

log(x(x-3)) = log(10) ⇒ x2 - 3x - 10 = 0
(x-5)(x+2) = 0 ⇒ x = 5 o x = -2

Descartamos y comprobamos

  • x = -2 no vale: incumple x > 3 y además daría un logaritmo de negativo.
  • x = 5 sí: log 5 + log 2 = log 10 = 1.
Solución: x = 5. El descarte de -2 no es un fallo del álgebra, es la condición de existencia del logaritmo.

Consejo que suma puntos

En ecuaciones con logaritmos, escribe siempre la condición de existencia (x>0, x-3>0, lo que toque) antes de despejar. Te ahorra perder tiempo con soluciones extraviadas y, sobre todo, evita presentar en el examen una raíz que no existe.
