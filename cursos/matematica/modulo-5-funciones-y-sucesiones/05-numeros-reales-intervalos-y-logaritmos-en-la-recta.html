Números reales, intervalos y logaritmos en la recta

Módulo 5 · Funciones y sucesiones

Objetivo Clasificar números reales, operar con intervalos y aplicar propiedades de logaritmos para simplificar expresiones.

El conjunto de los números reales R incluye naturales, enteros, racionales e irracionales. Se representan en la recta real sin huecos.

Clasificación

ConjuntoNotaciónEjemplos
NaturalesN1, 2, 3, ...
EnterosZ..., -2, -1, 0, 1, 2, ...
RacionalesQ12, -0.25, 0.‾3
IrracionalesIπ, √2, e
RealesR = Q ∪ Itodos

Intervalos

NotaciónDescripciónGráfica
(a, b)a < x < babierto
[a, b]a ≤ x ≤ bcerrado
(a, b]a < x ≤ bsemiabierto
(-∞, b)x < binfinito
[a, +∞)x ≥ ainfinito
El intervalo (a, b) NO incluye los extremos y [a, b] sí. Lo que decide es si el cierre es redondo o cuadrado.

Propiedades de logaritmos

loga(bp cq) = ploga b + qloga c
logabpcq = ploga b - qloga c

Logaritmos naturales y decimales

ln x = loge x, e ≈ 2.718, log10 x = log x
√2 ≈ 1.414213... es irracional: no se puede escribir como fracción exacta y su decimal no es periódico.

Ejemplo resuelto

Escribe en intervalo y representa: x ≥ 2 y x < 5.

Un intervalo semiabierto

El intervalo semiabierto es [2, 5): incluye el 2 porque el cierre es cuadrado, y excluye el 5 porque el paréntesis lo deja fuera.

---

Simplifica log 100 - log 102 + loga(a3).

log 100 = 2, log 102 = 2, loga(a3) = 3
2 - 2 + 3 = 3

---

Desarrolla log28x3y2.

log2(8x3) - log2(y2) = log2 8 + 3log2 x - 2log2 y
= 3 + 3log2 x - 2log2 y
Siempre comprueba el argumento: para que 8x3y2 sea positivo hacen falta x ≠ 0 y y ≠ 0, y como el signo de x3 es el de x, solo se admite x > 0.

Consejo que suma puntos

Al unir intervalos con "y", piensa en intersección (∩), y con "o" en unión (∪). Ese matiz evita errores frecuentes en desigualdades compuestas, y antes de dar por buena una respuesta comprueba que los extremos abiertos o cerrados coinciden con lo que pide el enunciado.
